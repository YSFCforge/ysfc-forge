YSFC.FORGE v1.16

Verktyg för att sammanfoga performances från flera Yamaha MODX/Montage Y2L-filer till en ny exportfil.

Stödda format
.Y2LMODX Performance Library✅
.Y2UMODX User Library (identiskt binärformat)✅
.X7LMontage Performance Library⚠ Se not
.X8LMontage Waveform Expansion⚠ Se not

* X7L/X8L använder ett annat internt format och kan inte slås samman direkt. Ladda in i synthen och exportera som .Y2L.

Kända begränsningar
Samples & waveform

Verktyget mergear performances. Fristående waveform-expansioner hanteras inte.

X7L / X8L

Importera i synth/ESP och exportera som Y2L innan användning här.

Reverse-engineered

Formatet är ej officiellt dokumenterat. Använd backup och testa exports.

Kompatibilitet

Primärt testmål: MODX M / ESP Plugin. Äldre system — verifiera med små bibliotek.

Arbetsflöde
  1. Dra in en eller flera .Y2L-filer
  2. Välj de performances du vill exportera
  3. Ange filnamn och klicka "Spara som Y2L"
  4. Importera den exporterade filen i MODX/Montage
