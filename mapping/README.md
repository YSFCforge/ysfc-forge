# Waveform mapping development assets

Cross-generation preset waveform mapping used by the Soundmondo/SysEx converter.

The legacy MONTAGE/MODX/MODX+ list contains 6,347 preset waveform identities. The mapping master records the cross-generation resolution to MODX M together with confidence/provenance information. The browser converter carries the production mapping in JavaScript for standalone use.

The known unresolved legacy item is ID 3720 `Sagat2 Sw`; it remains intentionally blocked rather than guessed.
