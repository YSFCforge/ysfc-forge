Stjärnbetyg:
  ★★★★★ = Binärverifierat med testfil(er) — 100% säker
  ★★★★☆ = Härledd från officiell källdata (Effect Type List, MIDI-tabell) — mycket säker
  ★★★☆☆ = MIDI-formel-härledd offset, ej binärverifierad — troligen korrekt
  ★★☆☆☆ = Osäker — känd kollision eller motstridiga data
  ❌     = Offset okänd / ej kartlagd

Förkortningar:
  u8     = unsigned 8-bit byte
  u16 LE = unsigned 16-bit little-endian (lo+hi*256)
  c64    = center=64 (raw = UI + 64)
  c128   = center=128 (raw = UI + 128)
  c256   = center=256 (u16 LE, raw = UI + 256)
  c50    = center=50 (raw = UI + 50)
  c247   = center=247 (u16 LE)
  c504   = center=504 (u16 LE, AN-X pitch cents)
  direct = raw = UI-värde direkt

Abs-adresser = absoluta DPFM-offsets (0 = första byte i perf-blocket)
PART+N = offset relativt PART_BASE=6708
ELEM+N = offset relativt AWM2_ELEM1_BASE=12532
