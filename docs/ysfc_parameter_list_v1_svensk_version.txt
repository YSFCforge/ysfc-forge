Notering om räkning:
  Löpnumren räknar UNIKA parametertyper, inte totalt antal fält.
  FM-X OP: 31 fält × 8 operatorer = 248 fält totalt → räknas som 31 här
  AWM2 Element: 22 fält × 8 element = 176 fält totalt → räknas som 22 här
  Assign positioner: 3 fält × 8 assigns → räknas som 3 prototyp + notering
  CA: 8 fält per slot, 8 slots per part + 8 slots perf-nivå

  Kodningsnycklar:
    direct  = raw = UI-värde direkt
    c64     = raw = UI + 64  (center=64)
    c128    = raw = UI + 128
    c50     = raw = UI + 50
    c247    = raw = round(UI_cent × 247/4800) + 247
    c256    = raw = UI + 256  (u16le)
    c504    = raw = UI_cent + 504  (AN-X pitch)
    bool    = 0 eller 1
    u8      = osignerad 8-bit
    u16le   = osignerad 16-bit little-endian

  Stjärnor = konfidensbetyg:
    ★★★★★ = binärverifierad
    ★★★★☆ = härledd från officiell källa (MIDI-tabell etc.)
    ★★★☆☆ = formelbaserad, ej binärverifierad
